# Shadow-Nova-Game
Shadows of Nova is a 2D sci-fi action game developed using Python and Pygame. The game takes place in a futuristic neon arena where the player must fight enemies, survive dangerous encounters, and earn points. It combines simple controls with exciting combat mechanics and a colorful visual style.

To run this game paate this code in terminal of python and then you can play this game
python -m pip install pygame
python game.py

Enjoy!
