SHADOWS OF NOVA — Python Game

Requirements:
- Python 3.10+
- Pygame

Install:
    python -m pip install pygame

Run:
    python game.py

Controls:
- WASD or Arrow keys: Move
- SPACE: Nova Slash (damages nearby enemies)
- E: Nova Burst (area attack; costs 35 energy)
- R: Restart after winning/losing
- ESC: Quit

Goal:
Survive the shadow creatures, collect shards, increase your score, and reach 3500 points!
